如何获取 GitHub 令牌？
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便填（例如“课表后台”），Expiration 选 1 年
  3. Repository access 选 Only select repositories，只选本网站的仓库
  4. Permissions → Repository permissions → Contents 选 Read and write
  5. 点 Generate token，复制以 github_pat_ 开头的令牌粘贴到这里

令牌只能修改这一个仓库。不要在别人的电脑上勾选“记住令牌”。
